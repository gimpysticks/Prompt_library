# ChatGPT Lockdown Mode (OCR Transcription)

> **Note:** This is a transcription of the text shown in the images. Some claims are marketing claims from the original post and should not be interpreted as independently verified.

---

## Introduction

**ChatGPT just added a hidden "Lockdown Mode" that stops it from leaking your private data.**

They hid it four menus deep and never announced it.

Here's where to find it and what it does.

---

## What It Actually Is

ChatGPT can browse the web, read your files, and take actions for you. Every one of those connections is a door someone can potentially exploit.

Attackers can hide invisible instructions inside webpages and documents. When ChatGPT reads them, it may be influenced into performing unintended actions. This is commonly called **prompt injection**, and it remains an active area of AI security research.

Lockdown Mode is presented as a way to reduce that attack surface.

---

## Why It Matters

If you've ever pasted contracts, bank statements, HR documents, or other personal information into ChatGPT and then used browsing or research features, the post argues that additional protections are worthwhile.

The author claims many users are unaware the setting exists.

---

# 1. Turn It On

Go to:

**Settings → Security → Advanced Security → Lockdown Mode**

Turn it on.

The post claims it is available on all account tiers.

---

# 2. Know What You Lose

According to the post, Lockdown Mode disables or restricts features including:

- Live web browsing
- Deep Research
- Agent Mode
- File downloading

It states that normal chat, uploads, memory, and image generation remain available.

---

# 3. Disable It Per Chat

When you need full capabilities for a specific conversation:

Select the **Lockdown** label above the message box and choose:

> Turn off for this chat

The idea is to keep protection enabled by default while allowing exceptions when needed.

---

# 4. Check Active Sessions

Go to:

**Settings → Security → Active Sessions**

Review every logged-in device.

Log out of any session you don't recognize.

---

## Takeaway

The post encourages users to:

- Enable Lockdown Mode
- Use it by default
- Disable it only when necessary
- Regularly review active sessions
