# Top 5 Nano Banana Prompts

## 1. Quality Improvement

``` text
Enhance image to ultra-high-resolution 4K with strict fidelity.

Preserve:
- face
- identity
- pose
- framing
- perspective
- clothing
- background

Recover:
- pores
- hair
- eyelashes
- fabric
- seams
- material details

Do not:
- reshape
- relight
- warp
- smooth
- stylize
- hallucinate details
```

------------------------------------------------------------------------

## 2. Create a Mini-Film from One Photo

``` text
Create a clean 3×3 storyboard grid from the reference image.

Keep the same:
- subjects
- identity
- location
- clothing
- hairstyle
- objects

Tell a realistic nine-frame story with:
- setup
- tension
- resolution

Use a photorealistic cinematic look, varied camera angles, and no text.
```

------------------------------------------------------------------------

## 3. Outfit Transfer ("Look at Yourself")

``` text
Change the entire outfit in the first photo to match the second.

Include:
- shirt
- pants
- shoes
- accessories
- watch
- sunglasses
- bag

Keep completely unchanged:
- pose
- person
- background
- lighting
- framing

Make the clothing realistic with correct golden-hour light interaction.
```

------------------------------------------------------------------------

## 4. Natural Skin

``` text
Edit the photo so the skin looks naturally realistic and photographic.

Add:
- pores
- micro-texture
- unevenness
- freckles
- peach fuzz
- natural sheen

Preserve:
- identity
- facial structure
- makeup
- hairstyle
- lighting
- color grading

Do not beautify, apply heavy makeup, or use plastic skin smoothing.
```

------------------------------------------------------------------------

## 5. Nine Camera Angles from One Photo

``` text
Create a clean 3×3 contact sheet from the reference photo.

Keep the same:
- scene
- subjects
- objects
- positions
- scale
- materials

Change only:
- camera angle
- camera height
- lens
- framing
- viewpoint

No captions, no watermark, consistent lighting, and consistent color grading.
```

------------------------------------------------------------------------

## Notes

These prompts are designed for image-editing models that accept
reference images. Results vary by model and may require small wording
adjustments.
