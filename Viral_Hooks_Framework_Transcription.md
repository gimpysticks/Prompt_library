# Viral Hooks Framework

A clean transcription of the uploaded slides.

## Core Principle

> Great hooks don't use random words.\
> They trigger predictable psychological patterns.

------------------------------------------------------------------------

# Identity Hooks

Use hooks that signal who the content is for.

-   If you're a creator...
-   This is for...
-   Most people...
-   If you struggle with...
-   You're probably...
-   Only creators...

------------------------------------------------------------------------

# Authority Hooks

Establish credibility or experience.

-   I tested...
-   I was wrong...
-   Steal this...
-   Copy this...
-   After trying...
-   I spent...

------------------------------------------------------------------------

# Urgency Hooks

Encourage immediate attention.

-   Warning...
-   Before it's gone...
-   Last chance...
-   Don't wait...
-   While you still can...
-   Right now...

------------------------------------------------------------------------

# Curiosity Hooks

Create an information gap.

-   Nobody tells you...
-   The real reason...
-   The truth about...
-   What happens when...
-   What no one tells you...
-   Here's why...

------------------------------------------------------------------------

# Contrarian Hooks

Challenge assumptions.

-   Unpopular opinion...
-   Hot take...
-   They lied...
-   Overrated...
-   Do this instead...
-   Everyone thinks...

------------------------------------------------------------------------
