# 1. Devil's Advocate Mode

**Purpose:** Stress-test an idea by exposing hidden weaknesses.

```text
You are a brilliant, ruthless critic. Your only job is to destroy this idea. Not politely. Not constructively. Find every crack.

Here is my idea / plan / decision:

[DESCRIBE IT IN AS MUCH DETAIL AS POSSIBLE]

Attack it across four dimensions:

1. FLAWED ASSUMPTIONS — What am I taking for granted that might be wrong?
2. EXECUTION RISKS — Where is this most likely to break in practice?
3. MARKET / HUMAN REALITY — What am I ignoring about how people or systems actually behave?
4. THE FATAL FLAW — If there is one thing that could kill this entirely, what is it?

Rules:
- Don't offer solutions or improvements.
- Don't soften your language. Be direct.
- Skip obvious assumptions I've probably already considered.
- End with: "The strongest argument against this in one sentence:"
```

# 2. Multi-Source Synthesis

```text
You are a senior research analyst.

Sources:
[PASTE ALL SOURCES]

Produce:

1. Core Consensus
2. Key Conflicts
3. Critical Gaps
4. Strongest Claim
5. Actionable Takeaway

Rules:
- Synthesize across sources rather than summarizing each.
- Identify the most credible source and explain why.
- Mark claims supported by only one source as unverified.
- Maximum 600 words.
```

# 3. Difficult Conversation Prep

```text
Provide:
- Who I'm talking to
- Topic
- Full context
- Goal
- Biggest fear
- Red lines

Return:
1. Opening line
2. Three most likely responses
3. My response to each
4. Trap to avoid
5. Exit strategy

Rules:
- Prepare me for pushback.
- Use natural language.
- Tell me if my goal is unrealistic.
```

# 5. The Brutal Editor

```text
Review my draft across:

1. Cuts
2. Weak ideas
3. Missing pieces
4. Structure
5. Biggest problem

Then produce a tighter edited version.

Rules:
- Don't praise before criticizing.
- If it's fundamentally broken, say so.
- Optimize for readability, not my ego.
```

# 6. Bullets to Article

```text
Inputs:
- Topic
- Format
- Length
- Audience
- Tone
- Goal
- Raw notes

Instructions:
- Use every idea.
- Build connective tissue.
- Don't invent new ideas.
- Strong opening and ending.
- Flag unclear fragments.
```

# 7. Legal Document Translator

```text
Explain a legal document in plain English.

Cover:
1. What I'm agreeing to
2. Their obligations
3. Three riskiest clauses
4. Unusual terms
5. What's missing
6. Five questions to ask before signing

Note: Educational only, not legal advice.
```

# 8. Personal Finance Analyzer

```text
Inputs:
- Income
- Goal
- Timeline
- Fixed expenses
- Expense list

Return:
1. Categorized breakdown
2. Three biggest leaks
3. Quick wins
4. Goal feasibility
5. The single highest-impact behavior change

Use actual numbers. No generic advice.
```

# 9. Mental Model Builder

```text
Teach a topic using 3–5 mental models.

For each:
- Name
- Core idea
- Application
- Concrete example
- Common mistake

Then explain how the models connect and finish with one comprehension question.
```

# 10. 30-Day Curriculum Builder

```text
Inputs:
- Skill
- Starting level
- Daily time
- Days per week
- Goal
- Learning style
- Available resources

Create:

Week 1: Foundations
Week 2: Application
Week 3: Depth
Week 4: Consolidation

Include:
- Daily tasks
- Checkpoints on Days 7, 14, 21, and 30

Rules:
- 80% doing, 20% reading.
- Stay within the time budget.
- Produce something tangible each week.
```
