# Contributing to Prompt Library

Contributions are welcome! Whether you want to add new prompts, fix errors, or improve existing content, here's how to get started.

## How to Contribute

### Adding a New Prompt File

1. Fork the repository and create a new branch:
   ```
   git checkout -b add/your-prompt-name
   ```
2. Create a new `.md` file using a descriptive, underscore-separated filename (e.g. `My_New_Prompt_Guide.md`).
3. Add your content using clear markdown formatting. Include a title heading (`#`) at the top.
4. Update [`README.md`](README.md) and [`index.md`](index.md) to include a link to your new file under the appropriate category.
5. Commit your changes and open a pull request.

### Improving Existing Content

- Fix typos, broken formatting, or unclear instructions.
- Reorganize or expand prompt examples where helpful.
- Update `README.md` / `index.md` if a file is renamed or recategorized.

## File Naming Conventions

- Use `Title_Case_With_Underscores.md`
- Avoid spaces and special characters in filenames
- Append `_OCR` to filenames that originated from image/OCR sources

## Categories

Place new files in the most relevant category in `README.md` and `index.md`:

- **ChatGPT & General AI Prompting** — general-purpose ChatGPT prompts, codes, and techniques
- **Claude AI** — prompts and codes specific to Claude
- **Image & Visual Prompts** — prompts for image generation and editing
- **Video & Cinematic Prompts** — prompts for video and cinematic content
- **Content Creation & Social Media** — prompts for social platforms and marketing
- **Productivity & Decision Making** — frameworks, planning, and life direction prompts
- **Resources & Tools** — curated links and tool lists
- **Projects** — larger, multi-part transcription or curation projects

## Guidelines

- Keep content focused and practical.
- Do not include prompts that promote harmful, illegal, or deceptive activity.
- Credit original sources where known.
- All contributions are shared under the [CC BY 4.0 license](LICENSE).
