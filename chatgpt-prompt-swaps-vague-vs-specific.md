# ChatGPT Prompt Swaps: Vague vs. Specific Instructions

Source: The Wize AI (`@thewizeai`)

## Introduction

### Words to Never Use in ChatGPT—Here Is Exactly What to Say Instead

Most bad ChatGPT answers are not the model's fault. They come from vague instructions like "make it better" or "give me ideas."

The word "better" means nothing to it, so it guesses. The fix is telling it exactly what better means.

## Avoid Asking Like This—Ask Like This

| Avoid asking like this | Ask like this |
|---|---|
| "fix this" | Find the problem and fix it without changing the way I speak. |
| "explain this" | Explain it like I'm a beginner and give an example. |
| "summarize this" | Summarize it in 3 points, 1 conclusion, and 1 action. |
| "make it shorter" | Cut it by 50% without losing the main idea. |
| "make it better" | Rewrite it so it can be understood in 5 seconds. |
| "give me ideas" | Create 10 original ideas about [topic] for [audience]. |
| "give me advice" | Give me 7 tips about [topic], ranked by impact. |
| "what do you think?" | Show me the strengths, mistakes, and areas to improve. |
| "help me with this" | Ask me 3 questions before giving me the solution. |
| "make it more persuasive" | Rewrite this to overcome this objection: [objection]. |
| "give me information" | Summarize the topic into the 5 most important points. |
| "give me examples" | Give me 3 examples and explain what I can learn from each. |
| "write something to sell" | Turn this into sales copy with a problem, desire, solution, and CTA. |
| "make it go viral" | Turn this into a 30-second Reel with a hook, content, and CTA. |
| "what should I do now?" | Tell me my next 3 actions and why. |
| "make it sound better" | Create 3 versions: clear, persuasive, and direct. |
| "I want some copy" | Write a caption with a hook that grabs attention. |
| "improve this text" | Find 3 weaknesses and create a better version. |

## The Principle

Notice what every good version has: a number, a format, or a constraint. Ten ideas. Three points. Under 50 words. In my voice.

Specific in, specific out. That is the entire skill.
