# Sifuyik AI Infographics --- Human Transcription Project

## Purpose

This document is the master transcription file for the infographic
collection.

The source images contain dense instructional content that is not
suitable for automated OCR alone. This project recreates the material in
clean, human-readable Markdown while preserving the structure and intent
of the originals.

# Formatting Rules

-   Use Markdown headings.
-   Preserve wording where possible.
-   Correct obvious OCR mistakes.
-   Convert diagrams into nested bullet lists.
-   Convert comparisons into Markdown tables.
-   Preserve prompt text inside fenced code blocks.
-   Preserve workflow order.
-   Add notes only when they clarify the original.

------------------------------------------------------------------------

# Deliverables

Because the complete transcription is expected to exceed the response
length of a single ChatGPT message, the finished project should be
divided into:

1.  Part 1 --- Images 1--3
2.  Part 2 --- Images 4--6
3.  Part 3 --- Images 7--9
4.  Part 4 --- Images 10--13

Each part should be a standalone Markdown document suitable for
Obsidian, GitHub, Notion, or other Markdown knowledge bases.
