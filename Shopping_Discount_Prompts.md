# Find Discounts Before You Buy

> The opening slides claim ChatGPT found a 30% discount in under a
> minute. Results vary and depend on current promotions and available
> information.

## 1. Find the Codes

``` text
I'm about to buy from:

[paste the URL or store]

Search the web for every currently working discount code,
promo code, cashback offer, and hidden deal available right now.

Skip expired offers.

List each one, what it saves, and where to apply it.
```

------------------------------------------------------------------------

## 2. Auto-Test Them *(requires Agent Mode if available)*

``` text
Turn on Agent Mode.

Go to the website, add:

[the item]

to the shopping cart and test each available code one by one
during checkout.

Tell me which single code—or combination, if allowed—produces
the lowest total price, then stop.
```

------------------------------------------------------------------------

## 3. Grocery Coupons

``` text
Here's my grocery list:

[paste your list]

I shop at:

[Walmart, Target, Kroger, etc.]

Search for all current coupons, digital offers,
store-app discounts, and weekly specials.

Tell me:

- which store has the lowest total this week
- which items should be purchased at each store
- any available cashback opportunities
```

------------------------------------------------------------------------

## 4. Find a Better Price

``` text
Before I buy:

[the item]

Search whether it's currently available for less elsewhere,
including other retailers, open-box offers, and refurbished
options.

Tell me:

- the lowest legitimate delivered price
- whether the price is likely to fall soon
- whether another retailer is likely to price match
```

------------------------------------------------------------------------

## 5. Lower a Monthly Bill

``` text
Here's a monthly bill I pay:

[paste the bill or describe the plan]

Research what new customers currently pay for an equivalent plan.

Tell me whether I'm overpaying and write a phone script
I can use to request a lower rate or a price match.
```

------------------------------------------------------------------------

## Notes

-   Some retailers prohibit stacking coupon codes.
-   Cashback programs may require activation before purchase.
-   Agent Mode availability depends on your ChatGPT plan and platform.
-   Live pricing and coupons change frequently, so results are
    time-sensitive.
