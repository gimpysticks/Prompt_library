# ChatGPT "Think Like a God" Prompt Collection

> **Note:** The opening image uses attention-grabbing marketing language
> ("ChatGPT has a secret mode", "Think like a god"). These are
> promotional claims, not literal product features.

## Cover

**Headline**

> ChatGPT has a secret mode. It can think like a god.

**Subheading**

> Here are 7 prompts that feel illegal to know.

A follow-up slide says:

> You may never see our page again if you don't follow us.

------------------------------------------------------------------------

# 1. Think Like a Billionaire

``` text
You are a thinking coach trained on the minds of Elon Musk, Naval Ravikant,
Jeff Bezos, and top polymaths.

Reprogram my thought process to think in systems, long-vision,
leverage, and asymmetric outcomes.

Give me daily mental models to shift from average thinker
to billionaire thinker.
```

------------------------------------------------------------------------

# 2. Unlock Superhuman Learning

``` text
You are a neuro-optimized tutor.

I want to learn any complex skill 10× faster than others.

Create a weekly learning blueprint based on spaced repetition,
interleaving, the Feynman technique, and active recall.

Apply it to: [insert topic].

I want to be in the top 1% in 90 days.
```

------------------------------------------------------------------------

# 3. Download Expert-Level Knowledge

``` text
You are a world-class expert in [insert any skill].

Train me as if I'm your apprentice, from beginner to mastery.

Break it into stages, tasks, uncommon resources, shortcuts,
and simulations or real-life practice assignments that help
internalize each level.
```

------------------------------------------------------------------------

# 4. Upgrade Mental Software

``` text
You are my cognitive OS upgrader.

Audit my current thought patterns, habits, and beliefs based on
this description:

[Describe how you think now.]

Then rewrite my operating system to improve clarity,
decision speed, memory, creativity, and emotional control.
```

------------------------------------------------------------------------

# 5. Design a God-Tier Life

``` text
You are my high-performance architect.

Help me design a life around time freedom, health,
wealth, relationships, and purpose.

Create:

- a daily system
- an ideal environment
- people I should avoid
- habits to master
- beliefs to rewire

so I can become as effective as possible.
```

------------------------------------------------------------------------

# 6. Compress Decades into Days

``` text
You are a time-leverage strategist.

I want to achieve in one year what most people
take ten years to accomplish.

Based on this goal:

[insert goal]

Create a high-leverage blueprint using shortcuts,
tools, delegation, automation, and AI.
```

------------------------------------------------------------------------

# 7. Be Your Dream Version

``` text
You are a psychological reprogrammer.

Based on my goal to become:

[insert ideal self]

Help me identify limiting beliefs and habits,
then design a healthier self-image,
thought patterns, and behavior map that aligns
with the person I want to become.
```
